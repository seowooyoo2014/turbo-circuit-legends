# Texture Slots

PBR 텍스처를 넣는 폴더입니다. 현재 버전은 외부 이미지 없이 코드 재질만 사용하지만, GLB를 추가할 때 이곳에 텍스처를 함께 둘 수 있습니다.

권장 이름:

- `arena_asphalt_basecolor.webp`
- `arena_asphalt_roughness.webp`
- `paint_basecolor.webp`
- `rubber_basecolor.webp`
- `metal_roughness.webp`

권장 규칙:

- 가능하면 `webp` 또는 압축된 KTX2 텍스처를 사용합니다.
- 실제 브랜드, 실제 경기장 광고, 상용 게임 UI 이미지는 사용하지 않습니다.
- 아스팔트, 고무, 금속, 유리, 페인트 재질을 분리하면 컷신에서 훨씬 입체적으로 보입니다.
